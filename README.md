# Sistema de gestión de tareas

Este proyecto consiste en el desarrollo de una aplicación web para la gestión de tareas, que permite crear, visualizar y organizar actividades de manera sencilla.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Funcionalidades
- Crear tareas
- Visualizar lista de tareas
- Organización básica de actividades

## Descripción
Proyecto académico desarrollado como parte de mi formación en Ingeniería de Sistemas, enfocado en el desarrollo Front-End y la aplicación de lógica de programación.
